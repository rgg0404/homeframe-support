# HomeFrame support and privacy

Public support and privacy pages for HomeFrame for iPad, developed by Ricardo Garcia Gonzalez.

- Website: https://rgg0404.github.io/homeframe-support/
- Privacy policy: https://rgg0404.github.io/homeframe-support/privacy.html
- Support: https://rgg0404.github.io/homeframe-support/support.html

Static HTML and CSS; no external fonts, analytics scripts or application source code. Contact is handled by the linked Google Form. Its owner manages responses privately in Google Forms. This repository does not store support submissions.

GitHub Pages publishes the root of the `site` branch. Edit the HTML and CSS there to update the public pages. Keep the privacy policy aligned with the shipping app and update its effective date when practices change.
